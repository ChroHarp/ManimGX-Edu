# 餘弦定理幾何圖解動畫專案 (Law of Cosines Visual Proof)

本專案採用 **Manim CE (Community Edition v0.21+)** 結合微軟神經網絡語音 **Edge-TTS (台灣男聲 `zh-TW-YunJheNeural`)** 與 **FFmpeg** 毫秒級無損混音管線，以視覺化幾何方式直觀證明「餘弦定理」（Law of Cosines）：

$$a^2 = b^2 + c^2 - 2bc \cos A$$

---

## 📐 幾何原理與數學推導

### 1. 原始三角形
考慮任意三角形 $\triangle ABC$：
* 底邊為 $c$
* 左邊為 $b$，右邊為 $a$
* 內角分別為：左下角 $\angle A$、右上角 $\circ$（即 $\angle C$）、右下角 $\times$（即 $\angle B$）
* 內角和滿足：$A + \circ + \times = 180^\circ$

### 2. 三塊放大三角形與接合
1. **第一塊（乘 $b$）**：
   * 三邊放大為 $b^2, ab, bc$。
   * 頂邊為 $b^2$（水平），右側邊為 $ab$，左側斜邊為 $bc$。
   * 就定位於左側。
2. **第二塊（乘 $a$）**：
   * 三邊放大為 $a^2, ab, ac$。
   * 特別高亮對應的共同邊 $ab$，其餘邊降低亮度，直觀呈現拼接依據。
   * 靠攏接合後，重合之 $ab$ 標籤淡出。
3. **第三塊（乘 $c$）**：
   * 三邊放大為 $c^2, ac, bc$。
   * 特別高亮對應的共同邊 $ac$，其餘邊降低亮度。
   * 旋轉平移至右側接合，重合之 $ac$ 標籤淡出。

### 3. 外框結構與平整性
* **頂邊平整直線**：在頂部交會點，三塊三角形頂角分別為 $\circ, A, \times$。因 $\circ + A + \times = 180^\circ$，頂邊自然形成一條無縫的水平直線，總長度為：
  $$\text{Top} = b^2 + c^2$$
* **底邊中央**：黃色三角形底邊長度為 $a^2$。

### 4. 左右垂直投影
* **左側投影**：
  * 左側斜邊長度為 $bc$，與水平底線夾角為 $A$（內錯角相等）。
  * 自左上角作垂直線向下投影，底邊水平長度為 $bc \cos A$。
* **右側投影**：
  * 右側斜邊長度同為 $bc$，與水平底線夾角同為 $A$。
  * 自右上角作垂直線向下投影，底邊水平長度亦為 $bc \cos A$。
* **底邊總長度**：
  $$\text{Bottom} = bc \cos A + a^2 + bc \cos A = a^2 + 2bc \cos A$$

### 5. 矩形上下邊等長與移項
整個外框為一完整矩形（兩側垂線等長且垂直於底邊），因此上邊長度等於下邊長度：
$$b^2 + c^2 = a^2 + 2bc \cos A$$

### 6. 直角特例延伸：動態變形密合成矩形（畢氏定理）
當頂角 $\angle A \to 90^\circ$（直角）時：
* $\cos 90^\circ = 0 \implies bc \cos A = 0$，底邊兩側的投影項縮減為 0。
* 兩側原本向外傾斜的斜邊 $bc$ 動態旋轉直立化，變為嚴格垂直邊，與矩形外框左右兩側重合。
* 高度調整為 $H = bc \sin 90^\circ = bc$。
* 綠色與藍色三角形變形為以頂角直角頂點 $V_{TL}, V_{TR}$ 為直角頂點的直角三角形；黃色三角形底邊 $a^2$ 擴展涵蓋整條底邊 $b^2 + c^2$。
* 三個直角三角形完美無縫密合成一個長方形（矩形），移項式化簡為：
  $$\mathbf{a^2 = b^2 + c^2}$$
  直接證得著名的**畢氏定理（勾股定理）**！

## 🚀 執行與重新建置

### 1. 僅渲染 Manim 動畫 (預設 480p 快速預覽)
```bash
manim -ql law_of_cosines.py LawOfCosines
```

### 2. 渲染 1080p 60fps 高清影片
```bash
manim -qh law_of_cosines.py LawOfCosines
```

```bash
python build_master_video.py
```
