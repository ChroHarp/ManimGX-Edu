## 三、未來配音整合指南（當欲啟用 Edge-TTS 時）

專案已內建 `manimgx_tw_helper.py` 的台灣男聲語音模組（`YunJheVoice`），未來若要一鍵生成配音，只需：
1. 在 `TWScene` / `ArcDegreeVertical` 宣告：
   ```python
   from manimgx_tw_helper import TWScene, YunJheVoice

   class ArcDegreeVertical(TWScene):
       voice = YunJheVoice(rate="+15%")
   ```
2. 將對應分鏡的 `self.play(...)` 換為 `self.say("台詞...", anim1, anim2)`，ManimGX 即會全自動排程語音、自動混音，並生成內嵌音軌的 MP4。
